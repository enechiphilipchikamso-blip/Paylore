# Wallet logos

These locally served icons identify the wallet options in Paylore's wallet chooser. The chooser loads them from this directory and does not fetch logo files from third-party servers at runtime.

| File | Official source |
| --- | --- |
| `phantom.svg` | https://phantom.com/_web_platform_assets/favicon.svg |
| `solflare.svg` | https://www.solflare.com/wp-content/themes/solflare-web-2024/static/ui/favicon/favicon.svg |
| `backpack.png` | https://backpack.app/icon/128x128.png |
| `jupiter.svg` | https://jup.ag/favicon.svg |

These are official site/app icons used only to identify wallet options. All product names, logos, and trademarks remain the property of their respective owners.
